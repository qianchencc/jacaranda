## 共享坐标与时钟

把“树在风中摆动”与“花瓣受风飘落”作为同一个现象实现。先规定坐标空间、单位和时间，不让两个模块各自猜测对方的变换。

Jacaranda 的模块契约为：

~~~js
// 植被局部坐标；出生点对应真实花朵实例。
vegetation.releaseSites; // { position, treeIndex, flowerIndex }
vegetation.updateWind(time);
vegetation.sampleWindPoint(restPoint, treeIndex, time, out);
vegetation.sampleWindNormal(restPoint, restNormal, treeIndex, time, out);

// 共享风速与阵风强度。
windGust(time);
windVelocity(x, y, z, time, out);

// 建筑承接与实体碰撞采用世界坐标。
architecture.catchSurfaces;
architecture.solidContact(x, y, z, radius);
~~~

当前工程中植被组只沿 Y 平移，出生点仅补上该偏移。迁移到允许旋转、缩放或任意位移的场景时，使用完整世界矩阵；方向、速度和法线也要采用各自正确的变换，不照搬只加 Y 的简化。

## 附着物变形

用一个空间连续的变形场覆盖树干、枝条、花朵和细叶。按高度、距树干的伸展距离和局部柔度分配响应：根部固定，主干缓慢，外侧枝梢明显。给不同树少量时差，避免整片同步摇摆。

保留 CPU 与 GPU 公式的对应实现。让花瓣释放位置、离线几何导出与实际着色器共享同一时刻的形变。

在实例矩阵之后、对象世界矩阵之前应用相同变形，并核对以下路径：

- 可见顶点的投影位置。
- 参与光照、阴影查找的世界坐标。
- 法线的变换；连续非刚性变形可用 Jacobian 的逆转置近似处理。
- 深度与距离阴影材质，而不只修改普通材质。
- 包围盒、包围球与裁剪范围，避免摆动枝梢被旧边界裁掉。

本工程的着色器注入对应 vendored Three.js r170。升级依赖时重新读取真实 shader chunks，检查所有插入点；不要假定字符串替换成功就等于 GPU 编译通过。

## 真实出生点与运动

从实际花簇锚点采样脱落位置，继承一部分枝条的瞬时速度。让阵风影响释放率和邻近花序，而不是在整个画面里等概率撒粒子。

用阻力让水平速度逐渐接近共享风速；为不同花瓣设置小幅终端下落速度差异，叠加低于主体输运幅度的摆动与翻转。为较慢帧分步积分，避免跳过狭窄承接面。

用实际轨迹预热填充初始画面。不要为“第一眼就有落花”把已随机下移的粒子直接放到屋顶或墙体内部。

用投影尺寸、背景对比、释放位置、可见持续时间和速度共同判断可读性。粒子池容量不等于每帧可见数量，几何进入屏幕也不等于通过遮挡测试后仍可见。

## 承接面与碰撞

为主要表面提供可采样的接口：

~~~js
{
  id, kind, bounds, heightRange,
  sample(x, z) // null 或 { height, normal, edgeDistance }
}
// solidContact 返回 null 或 { normal, depth, id }
~~~

从实际模型生成高度和边界；先以 bounds 排除无关区域，再用空间网格或简单几何采样。独立用真实网格射线验证采样器，而不是让两个同源近似互相证明正确。

下落时选择路径上最先遇到的有效承接面。处理圆角轮廓、烟囱、女儿墙、开口及重叠的檐口：内侧更高的檐口可能比金属雨棚更先接住花瓣。

水平撞墙时将花瓣推到表面外侧并去掉朝内的速度分量，使其可以贴墙继续下落。不要用建筑外侧的固定“安全走廊”反射轨迹；这样会连屋顶的合法落点一起排除。

## 接触与网格交接

用当前旋转、缩放后的花瓣顶点计算沿接触法线的最低支撑距离：

~~~text
support = -min(dot(normal, rotatedScaledVertex)) + smallClearance
~~~

让最低点先接触表面，再逐步转平与压低中心。仅将花瓣中心设为“屋顶高度加一点”会让翻转中的边缘穿入模型。

在狭窄肋条附近保留采样的 x/z；沿法线偏移中心可能横跨到相邻面，造成高度或法线突变。对波纹棚面，可用实际最高支撑高度配合较平稳的总体坡面法线。

实时花瓣交给积落网格时，保持位置、姿态、颜色和当时的显示尺寸一致。如果空中渲染用了近镜头尺寸上限，交接时不能恢复成未经限制的原始大小。

这些是接触可信的视觉近似；它们不等于完整的软体接触、空气流体或刚体仿真。

## 积落分布与规模

区分已有积落与新近落定。已有积落可以按树冠覆盖、背风边缘和少量艺术化密度片区初始化；实时落花则在接触后增加实际积落。

先设计疏密和空面，再添加随机性。在屋顶形成松散口袋，在雨棚形成断续片区，在入口保留动线。避免均匀覆盖，也避免每个角落重复同一个花堆。

让积落池有上限，并保留必要的初始基底，防止长时间运行后屋顶被环形缓冲全部替换为空白。把堆积厚度控制在花瓣尺度内，检查悬空、穿模与漂浮阴影。

将树形、初始积落、实时释放的随机数流分开，是后续复用时值得采用的改进。Jacaranda 当前积落与释放仍共享随机序列；改变初始密度会改变后续轨迹样本，这一点尚未在该工程中改造。

## 暂停与性能

- 暂停同一风动时钟，让枝条与脱落物一起停止；仍允许切换光照。
- 减少动态效果偏好应覆盖树木与花瓣，不能只隐藏一种运动。
- 实例矩阵尽量保持静态，将附着花簇的变形留在 GPU；避免每帧逐一重写大量花朵矩阵。
- 控制阴影刷新频率，但检查移动枝叶与影子的延迟是否可接受。
- 把初始化、每帧 CPU、主渲染、阴影和像素比分别测量；离线模拟耗时不能代表浏览器帧率。
