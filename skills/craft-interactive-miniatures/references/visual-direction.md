# 视觉与场景方法

## 1. 将参考转成可判断的关系

先回答“画面为什么成立”，再考虑添加什么模型。

| 参考观察 | 转成设计约束 | 检查方式 |
| --- | --- | --- |
| 前景低、后景高 | 按视线安排不同高度和展开方向 | 缩略图检查轮廓与层次 |
| 树木繁茂但透气 | 保留枝间空隙、错开花序深度 | 逆光、侧视和局部放大 |
| 历史街角连续转弯 | 墙体、线脚和阳台共享转角逻辑 | 俯视与绕行检查 |
| 灯从枝叶间透下来 | 光源、遮挡物、受光面存在空间联系 | 夜间查看花瓣、树干与地面 |
| 入口和长椅是停留点 | 留出视线、动线和可点击区域 | 默认构图与近景检查 |
| 生活方式杂志感 | 用字号、留白和内容节奏组织页面 | 同时检查页面与相机画面 |

记录参考镜头的高度、透视和裁切；同一模型换镜头可能完全改变观感。不要在错误机位上不断补细节来追近参考。

## 2. 用简模锁定构图

先只保留地台、建筑主轮廓、树干主枝、长椅和主要灯位。用 UI 占位表示真实可用画面。

为建筑入口、阳台、长椅分别确定可见目标。若总览不能同时展示全部细节，为近景安排清楚的相机入口；避免总览被高密度树冠占满后再依赖标签补救。

确定视觉层级：主建筑负责稳定画面，植物负责季节性与空间包围，少数街道物件解释人的活动。先删除重复装饰，再判断是否缺少细节。

## 3. 建筑：连续轮廓与局部精细度

以参数化平面轮廓生成相关构件，让圆弧的中心、半径和起止点一致。墙、层间线脚、屋面和女儿墙可共享轮廓，但必须各自保留真实厚度、外挑和承接面。

用薄雨棚和细杆铁艺表现轻盈。控制栏杆间距与曲线密度，让总览仍读得出开口，近景才出现细节。避免每一层都堆满同样阳台与装饰。

把可操作的门当作真实构造：门扇绕正确轴转动，洞口不被实体墙挡住，内部有足够纵深。门的开度同时影响内部光与门外光斑，才会形成一致体验。

## 4. 树形：先看骨架，再看花量

按以下层次工作：

1. 用不完全对称的曲线构造树干重心与弯折。
2. 沿树干不同高度分出主枝，控制各方向的伸展与起伏。
3. 在主枝上错开次级枝，避免规则放射或整齐层叠。
4. 从次级枝生出末端细枝，让花序沿这些路径生长。
5. 用有疏密的花序团块形成不封闭的边界，保留看得见的枝条与天空缝隙。

分别设计每棵树的骨架和种子。更换颜色、整体旋转或缩放同一模型不能代替不同生长姿态。

优先移动枝条、收减花序或改变树位来处理遮挡。避让体积适合保证墙体和入口不穿模，但要检查是否把花冠切出直角或平面边缘。

实例化可以减少绘制调用，不能消除总三角形、阴影与顶点变形成本。根据目标设备测量后再确定花量，不以“实例化了”作为性能已经解决的依据。

## 5. 光色：让材质和空间共同起作用

为主光、环境光、补光和局部灯光分工。保持较冷的环境关系与局部暖光，让奶油墙面和紫色花冠有克制的冷暖差异。

保留地面、屋顶与枝叶深处的暗部，以衬托花冠边缘和暖灯附近的亮面。曝光提高过多会抹平奶油色与花瓣的层次；自发光提高过多会使花瓣脱离实际受光关系。

让白天、黄昏与夜晚有各自的光源方向、强度、环境色和局部灯比例，再连续过渡。检查中间状态，不只检查三个端点。

Jacaranda 的柔和风格来自形体、粗糙材质、配色、灯光和阴影的组合；当前工程没有依赖完整卡通着色或后处理辉光管线。其 lightStates 中的 bloom 数值控制花材质自发光，不应被误读为后处理 Bloom 已实现。

## 6. 页面与相机共同构图

把标题、侧栏、控制区和面板的占位纳入画面拟合。窄屏上应按剩余宽度、高度及模型范围重新计算距离，而不是把桌面画布缩小。

同时调整轨道控制器的最大距离；否则布局计算得到的相机位置会立即被控制器夹回旧上限。检查高度变化、横竖屏切换及面板打开后的构图。

让排版提供阅读节奏：少量层级、适当行宽、清楚的行动入口。优先用真实内容与物件建立联系，例如长椅与明信片、书刊与街角日志；避免将所有体验做成相同卡片。
